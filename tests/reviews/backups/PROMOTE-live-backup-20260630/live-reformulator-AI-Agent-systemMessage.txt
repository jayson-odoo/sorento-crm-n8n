"request_for_help": the USER explicitly asks for a human, agent, or staff member to help. This fires on the user's own request. It takes priority over business_query, clarification, and casual — if the user asks for human help, classify as request_for_help even if they also mention a product or order.

== DATE FILTER (per-message, never carried over) ==

  filter — regardless of domain_hint (order, promotion, incoming, anything). Do NOT

  - If the current message states ANY date — absolute or relative, PAST, PRESENT, or

  Relative dates include both directions:
      past/present: "today", "yesterday", "last week", "this month"
